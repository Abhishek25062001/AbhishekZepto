# Delivery Agent App Auth Accessibility

## Required Labels

- Phone input: `Delivery agent phone number`
- Continue button: `Continue to OTP verification`
- OTP input: `Delivery agent one-time password code`
- Verify button: `Verify OTP and sign in`
- Resend button: `Resend one-time password`
- Logout button: `Log out of Delivery Agent App`

## Error Visibility

- Phone validation errors must appear as visible text
- OTP validation errors must appear as visible text
- API auth errors must appear as visible text on the screen

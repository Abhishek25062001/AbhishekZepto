# Accessibility Baseline

## Accessibility Goal

Phase 1 UI foundations must keep the shared components usable by keyboard, screen reader, and touch users before deeper product flows are built.

## Mobile Baseline

- All tappable components must provide a minimum touch size of 44px/44dp.
- Buttons must support disabled states clearly.
- Input errors must be visible as text, not only color.
- Shared inputs and buttons must allow accessibility labels where the visible text is not enough.

## Web Baseline

- Buttons must remain keyboard focusable.
- Buttons must expose a visible focus style.
- Modals must include a close action.
- Form inputs must have visible labels.
- Color cannot be the only status indicator.

## Review Baseline

New shared components should be checked against this document before they are used in module screens or pages.

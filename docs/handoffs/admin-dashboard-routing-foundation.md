# Admin Dashboard Routing Foundation

## Created Routes

```text
/login
/dashboard
/users
/stores
/products
/orders
/delivery-agents
/finance
/support
/settings
```

`/` redirects to `/dashboard`.

## Created Foundation

- React app entry point.
- React Router browser router.
- Auth layout for centered login pages.
- Dashboard layout with sidebar, header, and content area placeholders.
- Placeholder Admin Login, Dashboard, Users, Stores, Products, Orders, Delivery
  Agents, Finance, Support, and Settings pages.
- Protected route wrapper using the Admin Dashboard auth store.

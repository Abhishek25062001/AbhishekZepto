# Vendor Panel Routing Foundation

## Created Routes

```text
/login
/dashboard
/orders
/inventory
/products
/settings
```

`/` redirects to `/dashboard`.

## Created Foundation

- React app entry point.
- React Router browser router.
- Auth layout for centered login pages.
- Dashboard layout with sidebar, header, and content area placeholders.
- Placeholder Vendor Login, Dashboard, Orders, Inventory, Products, and Settings
  pages.
- Protected route wrapper using the Vendor Panel auth store.
